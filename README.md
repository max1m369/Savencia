# Groupe Savencia — Новогодняя рассылка «Вылет в Новый ГОД!» ✈️🎄

Корпоративная праздничная рассылка для сотрудников **Groupe Savencia** из трёх городов: **Москва**, **Уфа** и **Белебей**.

🌐 **Интерактивный эмулятор (GitHub Pages):**  
👉 **[Открыть онлайн-эмулятор Savencia](https://max1m369.github.io/Savencia/)**

---

## 📱 Интерактивный эмулятор (`index.html` / `emulator.html`)
Эмулятор позволяет в один клик переключаться между всеми 8 вариантами дизайна и проверять адаптивность одновременно на двух экранах:
- **💻 Компьютер / Outlook & Gmail Web** (600–740px)
- **📱 Смартфон (iOS / Android)** (375px)

В верхней панели навигации доступны быстрые переключатели: **Варфрейм**, **1**, **2**, **3**, **4**, **5**, **6**, **7**, **8** и режимы отображения (**Рядом**, **ПК**, **Смартфон**).

## 🛠 Технические требования и верстка
- **Gmail Anti-Clipping Safe:** Все варианты весят строго `< 100 KB` (порог обрезки Gmail — 102 KB).
- **Кросс-клиентность:** Протестировано для Microsoft Outlook, Apple Mail, Gmail, Яндекс.Почты и мобильных клиентов iOS/Android.
- **Исходники:** Чистый адаптивный код на фреймворке **MJML** с компиляцией в оптимизированный HTML.
- **Графика:** Векторная SVG-графика и оптимизированные Retina-ассеты.
